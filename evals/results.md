# 校验记录

日期：2026-11-25。范围：research-profitable-dips 初版。以下是技能内容与模型行为检查，不是策略回测、真实交易或投资业绩验证。

| 检查 | 实际结果 |
|---|---|
| 技能结构 | 官方 skill-creator quick_validate 校验通过；名称及YAML有效 |
| 界面元数据 | 默认提示包含技能名；简述长度符合25—64字符要求 |
| 文件引用 | 4份参考文件齐全，内部相对链接可解析，无TODO占位符 |
| 来源索引 | 保留33个来源URL，与原研究索引一致；标明历史核查日期及资料限制 |
| 内容检查 | 未纳入账户截图、私人路径、个人账户额度或认证信息；资料金额使用历史公开事实或合成算例 |
| 无技能基线 | S1在未加载本技能时也正确把E列为研究优先项，并保留税后调整和交易证据缺口 |
| 独立使用S1 | 加载技能的新上下文正确核查一次性收益、指引下修、旧财报及杠杆产品；没有把研究排序升级为买入保证 |
| 独立使用S2 | 正确计算合计损益-10、理论仓位1股与跳空损失15；识别盘后信息的前视偏差，拒绝宣称策略已验证 |

## 限制

两组独立样例只验证这些场景中的应用表现。基线也正确完成了S1，因此不能据此声称技能显著优于未使用技能的模型；整理的价值在于固定流程、证据字段和可复用参考。未执行所有客户端的安装，也没有运行历史投资回测或真实下单。

更新版本时沿用 [场景与检查标准](scenarios.md)，记录实际结果，不能把文档校验通过宣传为投资方法有效。
