## 3. 计划参数

只在相关输入已经明确时计算；将未确定字段留为未知。

| 字段 | 必须说明的内容 |
|---|---|
| 资金与损失预算 | 由用户提供或明确标为合成示例；检查整体持仓相关性 |
| 首次投入与总上限 | 包括所有追加金额；加仓需重新检验价值 |
| 入场 | 报价时间、交易时段、最高可接受买价、未成交处理 |
| 退出 | 事实失效条件、时间期限、价格规则分别记录 |
| 执行风险 | 跳空、流动性、停牌、部分成交、止损滑点 |
| 成本 | 当前券商与账户费用、换汇、价差、其他适用成本 |

合成算例：若计划损失5个货币单位，预设退出价距入场价5%，忽略费用、汇率与跳空时，对应持仓金额为5÷0.05=100。不得由此推导5%是最佳止损或实际最多亏5。

## 4. 模拟／实盘复盘日志

| 字段 | 记录要求 |
|---|---|
| 标的及时间 | 交易所、证券类别、信号确认时间、当时可知财报 |
| 入选／排除 | 保留所有合格事件；不买也写原因 |
| 原始规则 | 筛选阈值、持有期、仓位、退出规则、版本 |
| 价格与成交 | 买卖报价、真实或模拟成交、未成交及部分成交 |
| 资金流 | 所有买入、追加、卖出、入金、出金及分红日期金额 |
| 成本与币种 | 费用、价差、汇率；统一汇报币种 |
| 结果 | 已实现及未实现损益、现金、持有天数、最大回撤 |
| 基准 | 相同期间与资金可用时间；计入闲置现金 |
| 纪律 | 原计划与实际操作差异；事前理由与事后解释分开 |
| 结论 | 分清一次事件结果、过程质量和可重复的策略证据 |

5日和10日方案分别记录，不在事后逐笔选择最优持有期。连续若干笔模拟只能初步检查流程，不能作为稳定获利证明。

## 5. 经验／论文评审卡

| 问题 | 要记录的证据 |
|---|---|
| 谁在说、何时说 | 原文、发布日期、事件日期；作者和潜在利益 |
| 材料类型 | 社区自述／本人复盘／公告／统计研究／完整账户记录 |
| 实际证明了什么 | 限定对象、样本、持有期、口径及费用 |
| 没有证明什么 | 未展示交易、未核验流水、因果与可推广性限制 |
| 能转成哪条动作 | 具体、可观察、可复核的规则 |
| 怎样验证 | 新样本、固定规则、可成交价格、全部结果与基准 |

合成算例：9次各赚10、1次亏100，合计-10，胜率90%；不要遗漏尚未卖出的亏损。用平均盈利、平均亏损及成本解释结果，不能把胜率直接当成收益率。
